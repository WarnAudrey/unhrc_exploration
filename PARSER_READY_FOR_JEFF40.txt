================================================================================
WHAT THE PARSER DOES (Step-by-Step)
================================================================================

STEP 1: File Scanning
---------------------
• Reads the entire ENDF file into memory
• Scans every line looking for MF=8 MT=457 sections
• Extracts MAT numbers from columns 67-70
• Records (line_number, MAT) for each decay section found

STEP 2: Section Identification
------------------------------
• Identifies ALL decay sections (typically 3000+ for full JEFF)
• Groups sections by MAT number
• Reports: "Found XXXX decay section(s) across YYYY material(s)"

STEP 3: Parsing Each Section
----------------------------
For each MF=8 MT=457 section:

  a) HEAD Record (Line 1):
     • ZA (nuclide identifier) = Z*1000 + A
     • LIS (isomeric state level: 0=ground, 1=first excited, etc.)
     • NST (stability flag: 0=unstable, 1=stable)
     • NSP (number of radiation spectra to read)

  b) Half-life Record (unstable nuclides only):
     • T1/2 (half-life in seconds) with uncertainty
     • Excitation energies if multiple levels exist

  c) Decay Modes Record:
     • RTYP (decay type: 1=β-, 2=EC/β+, 4=α, etc.)
     • Q-value (total decay energy) with uncertainty
     • BR (branching ratio) with uncertainty
     • Reads NDK decay modes

  d) Radiation Spectra Records (NSP spectra):
     For each spectrum type (gamma=0, beta+=2, X-ray=8, Auger=9):
     
     • STYP: Spectrum type identifier
     • LCON: Continuum flag (0=discrete+continuous, 1=continuous only, 2=discrete only)
     • NER: Number of discrete transitions
     • FD: Discrete normalization factor
     • ER_AV: Average radiation energy
     
     Then for each discrete transition:
     • Energy with uncertainty
     • Intensity/emission probability
     • For gamma: conversion coefficients (ICC, ICK, ICL)
     • For beta+: intensity and branching

STEP 4: Branching Ratio Calculation
-----------------------------------
• For β+ decay: Sums all individual β+ transition intensities
• For EC decay: Calculates as (100% - β+ branching)
• Validates against total branching ratio from decay modes

STEP 5: Level Verification
--------------------------
• Groups all parsed sections by ZA (nuclide)
• Sorts levels by LIS value
• Checks for sequential LIS (0, 1, 2, ...) 
• Warns if gaps detected (e.g., found LIS=[0,2], missing LIS=1)

STEP 6: Output Generation
-------------------------
• Level Completeness Check section
• Detailed state information for each level
• Combined decay modes table (all nuclides, all levels)
• Summary statistics
• VERBOSE mode: ALL discrete transitions with full details
