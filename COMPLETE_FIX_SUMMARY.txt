================================================================================
                     FIX #2: SINGLE FILE SUPPORT
================================================================================

Problem:
  • Parser only accepted directories with multiple *.endf files
  • Failed on single large files like "Radioactive_Decay_Data_JEFF-40.endf"
  • Error: "No ENDF files found matching pattern '*.endf'"

Solution:
  • Modified load_from_endf_files() to auto-detect file vs directory
  • Single file mode: processes one large file with multiple sections
  • Directory mode: processes multiple files with glob pattern

Result:
  ✅ Single file mode works (JEFF-4.0 format)
  ✅ Directory mode works (ENDF-B-VIII.0 format)
  
Test Results:
  Single File Mode:  ✅ PASS
  Directory Mode:    ✅ PASS
